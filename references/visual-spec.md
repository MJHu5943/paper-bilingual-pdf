# Zotero 参考 PDF 的视觉与结构规格

本规格来自当前 Zotero 阅读器中打开的附件《Multi-Agent Collaboration Mechanisms: A Survey of LLMs》的 35 页中英对照 PDF。它只定义可复用的版式关系，不把论文标题、页数、图数或坐标当作新任务常量。

## 页面几何

- 来源 PDF 页面：`486×720 pt`。
- 成品页面：`1014×764 pt`。
- 关系：`2×486 + 42 = 1014`，`720 + 44 = 764`。
- 左页放在 `(14,14)`；右页放在 `(486+28,14)`；顶部和底部各留 `14 pt` 外边距，中间分隔带宽 `42 pt`。
- 顶部横幅位于来源页上方，左侧为 `ENGLISH ORIGINAL`，右侧为 `中文译文 / 原页 N 对照`，右上角显示短标题；中间分隔线使用浅灰细线。

## 文本与阅读顺序

- 左侧整页直接复用来源页面；原文页标题、双栏正文、表格、图片和参考文献都保留。
- 右侧正文使用深色中文衬线或清晰的 CJK 正文字体；段落首行缩进约一个中文字符，行距比西文原页略宽。
- 右侧标题用加粗、较大的字号；图注和表注与正文保持同一阅读栏，不单独做浮动卡片。
- 表格优先使用真实表格或高分辨率局部 PDF，保留行列线和原始相对宽度；长表允许在中文栏内等比缩放，但不可切掉列名或引用。
- 参考文献页仍保留英文条目可选择文本；中文栏逐条对应翻译题名或说明，不改变编号。

## 图、公式和链接

- 参考 PDF 的中文图保留了原始插画、线条、图例、节点、箭头和布局，只把已核对的英文自然语言标签局部擦除后插入中文。
- 复杂公式在中文栏使用原 PDF 裁图；不要重新排版或把截图放进不可定位的长段落。
- 参考文件仍有 405 个链接注释，包含 URI 和内部 GoTo 引用；输出必须至少保留同等数量的注释，并实际点击抽查引文和参考文献跳转。
- 来源 PDF 的英文正文可以被选择、复制和搜索。用 `pypdf` 或 `pdfplumber` 抽查文本层，用实际 PDF 阅读器抽查选区和跳转。

## 抽查页

- 第 1 页：标题、作者、摘要和元数据。
- 第 16 页：双栏正文、表格和章节标题。
- 第 17 页：大幅图及图注，检查图中文字替换和边界。
- 第 35 页：参考文献文本层与 URI 跳转。
